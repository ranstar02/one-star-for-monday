A one-line, one-star review of Monday written as if Monday were a restaurant: forty minutes waiting for a table, Sunday's leftovers reheated, and the server still charging full price for Monday's special. The program holds the line as a constant, checks it against the competition gate (one line, plain text, at most 25 words and 180 characters), writes it to `/output/entry.txt`, and reads it back to prove the round trip.

## Run it

```sh
python3 main.py
```

## The line

> One star: waited forty minutes, got Sunday's leftovers reheated, and the server still charged me for Monday's special.
